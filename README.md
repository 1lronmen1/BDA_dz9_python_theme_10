## Описание проекта

Проект выполняет загрузку, анализ и визуализацию событий ИБ из JSON-файла.

## Структура
- `data/events.json` — исходные данные
- `events_analysis.py` — основной скрипт
- `example.py` — скрипт образец
- `output/` — сохраняемые графики

## Запуск
1. Создать виртуальное окружение: `python -m venv .venv`
2. Активировать: `.venv\Scripts\Activate.ps1`
3. Установить зависимости: `pip install -r requirements.txt`
4. Запустить: `python example.py`
5. Запустить: `python events_analysis.py`

## Результат
Первый скрипт демонтрирует пример выполнения задания, второй скрипт выводит текстовый отчёт о распределении событий по типам сигнатур и строит круговую диаграмму.
